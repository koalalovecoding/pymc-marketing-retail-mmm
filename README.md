# PyMC-Marketing Retail MMM

An end-to-end Bayesian Media Mix Modeling project using synthetic retail marketing data and PyMC-Marketing.

## Planned Workflow

1. Synthetic data generation
2. Exploratory data analysis
3. Bayesian MMM specification
4. Prior predictive checks
5. MCMC fitting and diagnostics
6. Posterior predictive checks
7. Channel contribution and ROAS analysis
8. Response curve analysis
9. Time-based validation
10. Budget optimization
